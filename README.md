1. Scam and Fraud Detection

This is a machine learning based project for detecting possible scam or fraudulent messages.

The user can enter a message into the website, and the system analyzes it and gives a prediction along with a risk score and some reasons behind the prediction.

2. Features

* Detects possible scam/fraud messages
* Shows a risk score
* Shows possible risk factors
* Uses LIME and Anchor for explaining predictions
* Simple web interface
* Trained using a labelled dataset

3. Technologies Used

* Python
* Scikit-learn
* Pandas
* NumPy
* LIME
* Anchor
* HTML
* CSS
* JavaScript

4. How It Works

The basic process of the project is:

text
User enters message
        ↓
Text preprocessing
        ↓
Machine Learning model
        ↓
Scam / Legitimate prediction
        ↓
Risk score and risk factors
        ↓
LIME + Anchor explanation


5. Dataset

The model is trained using a dataset containing scam and legitimate messages.

The dataset is divided into labelled examples so that the model can learn the difference between suspicious and normal messages.

Example:

```text
Message                         Label
------------------------------------------------
Normal transaction message     Legitimate
Urgent payment request         Scam
Account verification request   Scam
Normal service update          Legitimate
```

 Machine Learning

The message is first converted into features that can be understood by the machine learning model.

After training, the model predicts whether a new message is likely to be:

* Scam
* Legitimate

The actual model and results may change depending on the dataset used for training.

## Explainable AI

The project uses two explanation methods:

### LIME

LIME helps show which parts of a particular message influenced the prediction.

### Anchor

Anchor provides rule-based explanations for the prediction.

These explanations are shown along with the model's result instead of only showing the final prediction.

## Risk Score

The website also displays a risk score based on the model's output.

Example:

```text
Prediction: Scam

Risk Score: 82/100

Risk Factors:
- Urgent language
- Payment request
- Suspicious link
```

The score is only an indication and does not guarantee that a message is actually fraudulent.

## Running the Project

Clone the repository:

```bash
git clone <repository-link>
```

Go to the project folder:

```bash
cd scam-fraud-detection
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the main application:

```bash
python Main.py
```

## Disclaimer

This project is made for educational and hackathon purposes.

The result produced by the model should not be considered proof that a message is fraudulent. Users should verify suspicious messages through official sources and should not share passwords, OTPs, card details, or other sensitive information.
